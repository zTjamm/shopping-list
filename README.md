# Покупки — список покупок для телефона

Простое офлайн-приложение (PWA) для учёта покупок: название, количество, цена —
и итоговая сумма, которая пересчитывается сама.

Сделано под Samsung Galaxy S25 Ultra (Chrome на Android), но работает в любом
современном браузере и на любом телефоне.

## Что умеет

- **Добавление товаров**: название, количество (можно дробное — 1,5 кг), цена за единицу.
- **Итоговая сумма** всего списка всегда видна в шапке, плюс прогресс «сколько уже куплено».
- **Отметка купленного**: тап по квадратику — товар уходит вниз и зачёркивается.
- **Редактирование**: тап по строке товара — название, количество, цена, удаление.
- **Справочник товаров** (вкладка «Товары»): всё, что вы добавляли, сохраняется
  вместе с последней ценой. В следующий раз достаточно начать вводить название —
  подсказка подставит цену.
- **История покупок**: «Завершить покупку» сохраняет список в историю с суммой,
  историю можно раскрыть и повторить одной кнопкой.
- **Сумма трат** по всем сохранённым покупкам.
- **Валюта**: ₽, ₴, ₸, €, $, £ (меню «⋮»).
- **Резервная копия**: экспорт и импорт JSON (меню «⋮»).
- **Офлайн**: после первого открытия работает без интернета.
- **Данные хранятся только на телефоне** (localStorage браузера), никуда не отправляются.

## Установка на телефон

Приложение нужно один раз открыть по ссылке `https://…` (или с локального сервера),
а затем добавить на главный экран:

1. Откройте ссылку в **Chrome** на телефоне.
2. Меню браузера «⋮» → **«Установить приложение»**
   (в некоторых версиях — «Добавить на главный экран»).
3. Подтвердите. На главном экране появится иконка «Покупки».

После установки приложение открывается в отдельном окне без адресной строки,
работает офлайн и обновляется автоматически при наличии интернета.

> Важно: установка и офлайн-режим требуют **HTTPS** (GitHub Pages, Netlify,
> Cloudflare Pages и т. п.). По локальному адресу `http://192.168.x.x` браузер
> не даст установить приложение — там доступен только обычный просмотр.

## Локальный запуск (для разработки)

```bash
cd shop
python -m http.server 8765
```

Затем откройте `http://127.0.0.1:8765` в браузере. `localhost` считается
безопасным источником, поэтому установка и офлайн-режим работают и без HTTPS.

## Публикация на GitHub Pages

Репозиторий с этими файлами в корне:

1. GitHub → **Settings → Pages**.
2. Source: **Deploy from a branch**, Branch: `main`, Folder: `/ (root)`.
3. Через минуту приложение будет доступно по адресу
   `https://<логин>.github.io/<репозиторий>/`.

## Структура

```
shop/
├── index.html              разметка экранов
├── styles.css              тёмная мобильная тема
├── app.js                  вся логика, без зависимостей
├── sw.js                   офлайн-кэш (service worker)
├── manifest.webmanifest    имя, иконки, режим приложения
├── icons/                  иконки 180, 192, 512 и maskable
└── generate-icons.ps1      генератор иконок (Windows, System.Drawing)
```

### Обновление версии

При изменении `index.html`, `styles.css` или `app.js` увеличьте `CACHE_NAME`
в `sw.js` (например, `shopping-cache-v3` → `shopping-cache-v4`), иначе телефон
продолжит показывать старую версию из кэша.

## Резервное копирование

Данные лежат в localStorage браузера. Если очистить данные сайта в Chrome,
список пропадёт — поэтому перед чисткой браузера делайте экспорт:
меню «⋮» → **«Сохранить копию данных (JSON)»**. Восстановление — «Загрузить копию данных».
