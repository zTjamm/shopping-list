# Покупки — приложение для учёта покупок

Простой список покупок для телефона: название, количество, цена — и итоговая
сумма, которая пересчитывается сама. Есть два варианта:

| Вариант | Что это | Как получить |
|---|---|---|
| **Android-приложение (APK)** | Настоящее приложение: иконка в меню, работает без браузера и интернета | [скачать APK](https://github.com/zTjamm/shopping-list/releases/latest) |
| **PWA (сайт)** | То же приложение, но ставится из Chrome | https://ztjamm.github.io/shopping-list/ |

## Установка APK на Samsung S25 Ultra

1. Откройте на телефоне ссылку
   **https://github.com/zTjamm/shopping-list/releases/latest**
   и скачайте `pokupki-1.0.apk` (кнопка «Download»).
2. Откройте скачанный файл (уведомление о загрузке или «Мои файлы» → «Загрузки»).
3. Android спросит разрешение на установку из этого источника — включите
   «Разрешить для этого источника» и нажмите «Установить».
4. Готово: в меню приложений появится «Покупки» с зелёной иконкой.

Если Play Protect предупреждает о неизвестном разработчике — это нормально для
APK вне Google Play: нажмите «Подробнее» → «Всё равно установить».

## Что умеет

- **Добавление товаров**: название, количество (можно дробное — 1,5 кг), цена за единицу.
- **Итоговая сумма** всего списка видна в шапке вместе с прогрессом «куплено N из M».
- **Отметка купленного**: тап по квадратику — товар уходит вниз и зачёркивается.
- **Редактирование**: тап по строке — название, количество, цена, удаление (с отменой).
- **Справочник товаров** (вкладка «Товары»): всё добавленное сохраняется вместе с
  последней ценой; при вводе названия подсказка подставляет цену.
- **История покупок**: «Завершить покупку» сохраняет список с суммой, историю можно
  раскрыть и повторить одной кнопкой.
- **Сумма трат** по всем сохранённым покупкам.
- **Валюта**: ₽, ₴, ₸, €, $, £.
- **Резервная копия**: экспорт/импорт JSON. В APK копия сохраняется в папку «Загрузки».
- **Офлайн и приватность**: никаких разрешений, никакого интернета, данные только на телефоне.

## Где хранятся данные

Список хранится во внутреннем хранилище приложения (WebView localStorage).
При обновлении APK той же подписью данные сохраняются.

Чтобы не потерять список при удалении приложения или очистке данных, делайте
резервную копию: меню «⋮» → **«Сохранить копию данных (JSON)»**.

## Сборка APK

Нужны JDK 17 и Android SDK (platform 34, build-tools 34.0.0). Если они лежат
в `%LOCALAPPDATA%\Temp\opencode\android`, путь можно не указывать.

```powershell
# из корня проекта
powershell -NoProfile -ExecutionPolicy Bypass -File .\android\build.ps1
```

Скрипт собирает всё без Gradle: `aapt2` → `javac` → `d8` → `zipalign` → `apksigner`.
Готовый файл: `android\dist\pokupki-1.0.apk`.

- Сборка идёт во временной папке с ASCII-путём — `aapt2` не понимает кириллицу в путях.
- Ключ подписи `android\pokupki.keystore` (пароль `pokupki`) лежит в репозитории,
  чтобы обновления ставились поверх старой версии. Для Google Play нужен свой ключ.
- Иконки пересобираются из `generate-icons.ps1` (System.Drawing).

## Структура

```
├── index.html              разметка интерфейса
├── styles.css              тёмная мобильная тема
├── app.js                  вся логика, без зависимостей
├── sw.js                   офлайн-кэш для PWA
├── manifest.webmanifest    манифест PWA
├── icons/                  иконки сайта (180, 192, 512, maskable)
├── generate-icons.ps1      генератор иконок (сайт + Android)
└── android/
    ├── AndroidManifest.xml
    ├── java/com/ztjamm/pokupki/MainActivity.java   WebView + мост для сохранения файлов
    ├── res/                                       строки, тема, иконки
    └── build.ps1                                  сборка APK без Gradle
```

## Обновление версии

- APK: поднимите `-VersionName` / `-VersionCode` при сборке.
- PWA: увеличьте `CACHE_NAME` в `sw.js`, иначе телефон покажет старую версию из кэша.
